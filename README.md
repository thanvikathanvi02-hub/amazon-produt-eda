📊 Amazon Product Data Analysis (EDA Project)

📌 Project Overview
This project is an Exploratory Data Analysis (EDA) on an Amazon product dataset containing 1465 entries. The aim is to analyze product categories, pricing, and ratings to extract meaningful insights.


 📁 Dataset Information
The dataset includes:
- Product ID
- Product Name
- Category
- Actual Price
- Discounted Price
- Rating
- Rating Count
- Reviews



 🧹 Data Cleaning Performed
- Handled missing and inconsistent values  
- Converted price columns into numeric format  
- Extracted main categories from complex category structure  



 📊 Exploratory Data Analysis (EDA)
The following analyses were performed:
- Category-wise distribution of products  
- Revenue analysis by category  
- Rating distribution of products  
- Price analysis across categories  
- Data visualization using Matplotlib  



 📈 Key Insights
- Certain categories dominate overall sales  
- Price variation is high across different product types  
- Most products have ratings between 3.5 to 4.5  
- Category structure plays a key role in analysis  


 🛠 Tools & Technologies Used
- Python  
- Pandas  
- Matplotlib  
- Google Colab  


 💡 Learnings
- Data cleaning techniques for real-world datasets  
- Exploratory Data Analysis (EDA) workflow  
- Data visualization and insight generation  
- Handling structured and semi-structured data  



 🚀 Project Outcome
This project helped me understand how raw data can be transformed into meaningful insights using Python.
